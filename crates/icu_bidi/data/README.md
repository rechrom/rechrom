# Unicode security data

Unmodified files from the Unicode Security Mechanisms data (UTS #39),
version 16.0.0, <https://www.unicode.org/Public/security/16.0.0/>:

- `confusables.txt`: prototype mappings for `SpoofChecker::Skeleton`.
- `IdentifierType.txt`: Identifier_Type values; `Recommended` and `Inclusion`
  form ICU's `uspoof_getRecommendedSet` ∪ `uspoof_getInclusionSet`.
