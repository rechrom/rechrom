# Bundled font resources

`Roboto-Regular.ttf` is the unchanged Skia resource fixture imported from
`src/third_party/skia/resources/fonts/Roboto-Regular.ttf` in the supplied
Chromium/Skia source archive. It is used by the browser's fallback font
catalog and rendering/font regression tests.
